# Island TV Wall
Free official Dominica live streams as a TV. Open https://madinc47-prog.github.io/tv-wall/ and press ⏻.
- Add a channel: edit `channels.json` (instructions in its `_help` field). Types: youtube (UC channel id), hls (.m3u8), radio (mp3/aac URL), facebook (public video URL), link.
- Add an event: edit `events.json`. Dates YYYY-MM-DD in America/Dominica; use "TBA" when unknown; always include `source`.
- Keys: ↑/↓ channel, ←/→ volume, 0-9 channel number, G guide, E events, I info, M mute, W 2×2 wall, F fullscreen, P power.
